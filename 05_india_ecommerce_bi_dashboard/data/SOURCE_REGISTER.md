# Data provenance — BI dashboard

The dashboard uses the Project 01 synthetic e-commerce case dataset. It does not add a second or independent dataset. All Indian geography labels and KPI values are illustrative. A visible dashboard disclosure is required: "Synthetic demonstration data — not actual Indian marketplace transactions."

The Power BI and Tableau assets are provided as import-ready extracts, measures and build instructions. Native `.pbix` and `.twbx` files are not included in this repository.
