# Tableau dashboard build guide

1. Open Tableau Desktop/Public and connect to `data/processed/powerbi_table_orders.csv` (generated by Project 05 export script).
2. Confirm `order_date` is Date, `order_value_inr` is Number (decimal), `is_late_delivery` is Number (whole), and `review_score` is Number (decimal).
3. Create calculated fields:
   - Delivered Revenue: `IF [order_status] = "Delivered" THEN [order_value_inr] END` (aggregate with SUM).
   - Delivered Orders: `COUNTD(IF [order_status] = "Delivered" THEN [order_id] END)`
   - Late Delivery Rate: `SUM(IF [order_status] = "Delivered" AND [is_late_delivery] = 1 THEN 1 ELSE 0 END) / SUM(IF [order_status] = "Delivered" THEN 1 ELSE 0 END)`
   - Average Review: `AVG([review_score])`
4. Build sheets: KPI strip, monthly delivered revenue, revenue by state, category contribution, order-status mix, late delivery vs review.
5. Add dashboard filters for State, Category, Payment Method, and Order Date; apply to all relevant worksheets.
6. Add a visible caption: `Synthetic demonstration data — not actual Indian marketplace transactions.`
7. Save as `.twb` or packaged `.twbx` from Tableau Desktop.

A native Tableau workbook is not bundled because it must be saved and validated by Tableau Desktop.
