# Data provenance — e-commerce analytics

`india_ecommerce_orders_demo.csv` is a reproducible synthetic dataset generated for this portfolio. It contains illustrative Indian state/city labels and generated orders, categories, amounts, fulfilment durations and reviews. It is not scraped from, supplied by, or representative of any Indian retailer or marketplace. All revenue, review and delivery findings are demo-only.

If replacing it with a public dataset, record the exact publisher, dataset title, download date, license/terms, data dictionary and transformation steps before committing the raw file. Do not redistribute datasets without confirming permission.
